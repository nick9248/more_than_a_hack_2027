# Third-party notices and data attribution

The competition evaluation code and tactical-format reader originate from Metrica Sports' MIT-licensed challenge repository. The copyright and MIT grant are retained in [LICENSE](LICENSE). Competition match assets are separately restricted and are not included.

IDSSE: Bassek, Rein, Weber and Memmert (2025), *A public dataset of synchronized spatiotemporal and event data in elite soccer*, DOI https://doi.org/10.1038/s41597-025-04505-y, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Transformations include coordinate parsing, resampling, artificial missing observations and model fitting, as recorded in [TESTING_REFERENCE.md](TESTING_REFERENCE.md). Dataset files are not distributed here.

Metrica Sports public sample data: https://github.com/metrica-sports/sample-data. Used with the provider's community-analysis and source-acknowledgement permission; no named standard licence is asserted. Sample event-derived evaluations do not establish full-match possession truth.

ELASTIC benchmark timing annotations: https://github.com/hyunsungkim-ds/elastic, CC BY 4.0 for benchmark data. Only J03WMX/J03WN1 training annotations were acquired. The source code is MPL-2.0 and has not been incorporated or executed. Downloading annotations does not mean they were used to fit the selected model.

SkillCorner public data: https://github.com/SkillCorner/opendata. Its licence notice follows. Source revisions and actual training/evaluation roles are recorded in [TESTING_REFERENCE.md](TESTING_REFERENCE.md), including the original nine-match release used for the final Barcelona–Real Madrid diagnostic. Dataset files are not distributed here.
